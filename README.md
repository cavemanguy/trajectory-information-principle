# Trajectory Information Project

Independent research on learned recurrent dynamics, trajectory structure, latent geometry, history-dependent computation, and active latent interrogation.

**Preservation rule:** preserve successful, negative, ambiguous, superseded, exploratory, and prototype work. A failed explanation is not the same as a failed phenomenon.

The central scientific question remains:

> **What meaningful computational structure emerges in the native evolution of internal state through time, and can that structure be understood, measured, causally tested, and eventually used practically?**

Observers are measurement tools. Perturbations are optional causal/control tools. Neither is assumed to be the source of trajectory information. Accuracy and speed are not the primary scientific objectives; task competence is an interpretation safeguard. No architecture, observer, or active intervention is assumed to establish an independent phase code or information beyond complete state plus transition map.

## Current empirical picture

**R8-AD6:** tangent perturbations retained about 1.231× their initial error after three autonomous recurrent steps, versus 0.726× for matched transverse perturbations. The difference was +0.505, CI [+0.409,+0.597], positive 12/12. Tangent perturbations also produced greater terminal functional damage. This supports local tangent–transverse anisotropy within the R8 organism, not a universal phase variable or a mechanism beyond ordinary local Jacobian sensitivity.

**R9-T1:** the continuously driven GRR failed temporal competence (R9-D); the specific RNN–Transformer–RNN sandwich showed a return disadvantage (S−). A small history-accessibility effect passed, but R8's anisotropy did not transfer. The benchmark was solvable by the Transformer control, so the failures are specific to the tested organism and architecture/training arrangements.

**R9-H1:** learned interrogation, recurrent attention control, and low-rank modulation produced positive anomaly-screen classifications. The two serial orders behaved differently; both parallel branches contributed under ablation, but the predicted clean specialization was not established. Perturbation teaching and teacher-off persistence were unsupported. The interrogator's controller signal alone decoded the answer at 27.17%, close to its full-arm 28.46%, leaving an important answer-channel alternative despite the frozen audit's non-confounded classification.

**R9-S1:** all seven swarm variants missed the modest task-validity floor; only the monolithic control passed. The heterogeneous ring showed low-competence positive joint-history, complementarity, and communication-dependence signals, but effects were uneven and no collective-memory mechanism, synergy, wave, or essential chronological code was established. Shared-weight swarms largely remained near chance. Their failures and all seed records are preserved.

These findings do not establish architecture novelty, universal trajectory encoding, exact internal logic recovery, or practical superiority. Positive screens require independent confirmation, and a failed explanation is not a failed phenomenon.

## Active Flow Observer — proposed next direction

The user's engineering vision is an RNN continuously observing a black box's state-space flow, an automated perturber selecting targeted bits or directions, and a Transformer operating alongside the system to emit a human-readable semantic stream. The initial scientific target is narrower and testable: **recover identifiable operations from a frozen, instrumented system using native state history and isolated perturbation responses, while ruling out simpler explanations and answer leakage.**

The preparation protocol separates native capture, causal intervention, semantic decoding, and continuous integration. It begins with known-ground-truth operations, full-state and passive-history baselines, controller-only controls, and held-out counterfactual tests. The semantic output must support uncertainty and abstention. Neural layer depth, token generation time, dynamical step index, and wall-clock milliseconds are not interchangeable. Exact millisecond-by-millisecond logic reconstruction is a research aspiration, not an established capability.

No AFO scientific run has begun. Its source model, interface, complete preregistration, seeds, and gates must be frozen before outcomes. Existing R9 failed gates will not be rescued or reinterpreted. No experimental results are merged to main by this documentation update.
