# AFO-1 — Active Flow Observer Preparation

Status: **scaffold only; no scientific run authorized or launched**. This directory does not contain a trained observer, a semantic decoder, a selected neural black box, or an empirical result. It must not be used as evidence of real-time logic recovery.

The research design is in [Active Flow Observer](../../docs/ACTIVE_FLOW_OBSERVER.md), the related-work review is in [Literature](../../docs/ACTIVE_FLOW_OBSERVER_LITERATURE.md), and the preceding experimental evidence is in [R9 Current Synthesis](../../docs/R9_CURRENT_SYNTHESIS.md).

`protocol.py` supplies JSON-serializable trace frames, monotonic observation timestamps, bounded action descriptions, explicit unsigned-integer XOR, and paired isolated continuations. The `FrozenSystem` adapter must implement complete mutable-state snapshot/restore, a read-only observed-state projection, a truthful frozen-parameter fingerprint, stepping, and legal perturbations. `paired_probe` forks the source twice and compares responses while checking that the source snapshot and fingerprint remain unchanged. It never invokes a step or perturbation on the source. The adapter, not the protocol alone, must guarantee that copies do not share mutable storage, that all mutable state is captured, and that the fingerprint actually covers the model parameters. It must also whitelist permitted input and observation fields so no target labels or privileged program traces leak to the observer. These requirements are not yet validated on a neural model.

From this directory, run `python -m unittest -v test_protocol.py`. The four structural tests cover deterministic replay/source immutability, zero-action identity, action validation and integer-bit bounds, and rejection of aliased or mismatched forks. The source was compiled and all four tests passed locally before publication. The repository copy of `protocol.py` was verified against the tested Git blob SHA `86f1f6a9e88d31aa97ab98d2597ac350617272e6`. These are outcome-free preparation checks, not experimental observations.
