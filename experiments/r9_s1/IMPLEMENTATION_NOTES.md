# R9-S1 implementation freeze notes

These details resolve measurement and execution choices before scientific outcomes. They do not amend the original preregistration or change its gates.

The history probes use normalized ridge normal equations with regularization scaled by sample count, an unpenalized intercept, and validation cross-entropy selection. The frozen native chronology reader is evaluated with its two displacement blocks reversed; separately retrained integrated, first-only, and final-only readers test whether simpler summaries suffice. Reversing feature blocks and retraining an otherwise identical linear model would be a vacuous control. Joint and node probes report their feature dimensions; the complemented joint probe must also beat the duplicated-best-node control to receive the conservative candidate label.

The fixed random graph is the first strongly connected degree-two draw. Dynamic learned routing selects two incoming sources per receiver. Shared-weight nodes with identical inputs may remain symmetry-equivalent; this is not forced specialization. The disconnected model retains unused message parameters, so both declared and gradient-bearing parameter counts are recorded. A 64-dimensional monolithic GRU is not parameter-matched and is never described as such.

Communication shuffles are deterministic, within absolute time and event type, and across episodes. Full and disconnected graph rewiring is an identity/noninformative control. Node state replacement is an off-manifold intervention with matched current event and payload; matched-key and different-key donors are reported separately. The local-history comparison preserves the complete rule definitions and exact future continuation, while resampling earlier DATA values. None of these interventions is part of native training.

The classifier reports nominal seed-bootstrap intervals and screening labels, not multiplicity-corrected discovery claims. Missing measurements and missing family artifacts are invalid rather than silently dropped. Nonestimable donor strata are represented explicitly with counts and null values. The source manifest validates the exact frozen R9-T1 Git blob and the implementation commit. Model and optimizer checkpoints, complete family records, and full aggregate outputs are preserved as immutable run artifacts. Results publication is append-only on r9-s1-results and never merges into main.
