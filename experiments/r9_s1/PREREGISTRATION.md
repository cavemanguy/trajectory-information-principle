# R9-S1 — Recurrent Swarm Dynamics

Status: preregistration frozen before implementation, smoke outcomes, and scientific outcomes. This is a new experiment, not a rescue or amendment of R9-T1 or R9-H1. The parent is the frozen R9-H1 implementation commit b8147b6b1c51f0eb4b475ebc7fd07d1c0abd0a39; no H1 result is a training input. Preserve all earlier results.

## Question and boundaries

Can learning organize task-relevant structure in the native collective evolution of small interacting recurrent systems, and does communication topology change that organization? Accuracy and speed are not primary objectives. Task accuracy is an interpretation floor. The experiment does not assume attractors, waves, oscillations, phase, synchronization, specialization, or information beyond complete state plus transition map. No dynamical loss, probe loss, or geometry regularizer is used in training. A useful readout is not evidence of information creation, and joint decodability alone is not information-theoretic synergy.

## Architecture

Eight cells, hidden width 8 each, total hidden width 64. Common token encoder: type embedding16 + payload embedding16, LayerNorm16, shared linear16->8. Fixed input ports: nodes0,1 receive KEY events; nodes2,3 receive REGIME and ACTIVATE; nodes4,5 receive DATA; nodes6,7 receive DISTRACTOR. A node receives zero on other event types. All events remain legal and all architectures receive the same full stream collectively. No target labels or active-key labels enter the forward path. No position or regime-specific learned role is imposed beyond these input ports.

Each cell sends a learned 8->4 message. Synchronous update from previous states only: m_j=M(h_j); a_i=sum_j A_ij m_j; h_i'=GRUcell([local_input_i,a_i],h_i). Shared cells use one parameter set; heterogeneous cells use independent parameter sets, vectorized over nodes. Standard reset/update/candidate GRU equations, no attractor or trajectory constraints. PAD freezes state. A common joint readout maps the flattened64 state through Linear64->128, GELU, Linear128->16. No raw-input bypass at readout. All graphs are directed receiver-by-sender adjacency matrices, exclude self edges, and normalize incoming weights. Exact parameter counts reported.

Arms: DISCONNECTED (no messages); RING (bidirectional degree2 ring); RANDOM (fixed degree2 random strongly connected directed graph, first valid deterministic draw); FULL (all seven other cells, uniform weights); LEARNED (state-dependent query/key dot-product routing, width4, top2 incoming neighbors, softmax temperature1, no self edges); RING_HET and FULL_HET (independent cell/message parameters, otherwise same graphs); MONOLITHIC (ordinary GRU64 with complete raw event embedding16 and the same readout). Learned routing's extra parameters are reported and not hidden as a matched-capacity comparison. Shared graph arms have identical trainable parameter counts. All initializations use independent deterministic namespaces. No graph is trained to match a desired topology or role.

Below-floor arms are V-; all outcomes are preserved and any signed anomaly is LOW_COMPETENCE_A+/A-. There is no rank or speed gate and no competence-triggered retraining. All diagnostics run as a complete frozen screen; failing an interpretation floor never authorizes rescue. Primary contrasts use paired family values, 20,000 seed-bootstrap resamples, fixed bootstrap seed91093, percentile95% CI. ## Native measurements — first, no interventions

Primary latent target is active episode-specific key, which is required but not directly supervised. Answer decoding is reported separately on DATA events. Train probes on disjoint episodes and choose ridge regularization from [0.0001,0.01,1,100] using validation cross-entropy; test is untouched until selection. Standardize from training data only; include intercept, do not regularize intercept. Report feature dimension, class balance, validation choice, test accuracy and cross-entropy. All comparison probes use the same procedure. Probe samples at eligible positions t>=2, active key defined, non-PAD; answer probes use DATA only. Sample whole episodes before flattening. Shuffles are within matching absolute time/event type, across episodes, never conditioned on hidden key or label. Deterministic disjoint train/validation/test permutations.

HISTORY: for each node and joint64 state, compare state h_t, [h_t,delta_t], [h_t,delta_t,delta_{t-1}], displacement only, state plus shuffled displacement, and state plus zero/duplicated features. H1=one-step-state; HS=one-step-shuffled; H2=multi-step-state. The joint and node-specific measurements are separate; no claim of essential chronology follows merely from H1 or HS. A history candidate needs H1 and HS both A+ on the same frozen target/stream, with the competence qualification. The primary collective-history contrast is the joint hidden-key stream.

COMPLEMENTARITY: train separate node probes; compare the joint64 representation to the best single node, best pair of nodes, a shuffled-pair joint control preserving one anchor node, and a rank-matched duplicated-best-node/zero-padded control. Select the best node/pair on validation only; report test values without selecting on test. All node probe features are padded to64 and receive the same ridge procedure; single-node replicas are separately reported to expose regularization/capacity effects. Joint gain over best node and over shuffled pairing are both required for a complementary-accessibility candidate. These are accessibility and capacity-controlled clues, not proof of synergistic information.

NATIVE ORGANIZATION: report per-node and joint hidden-key access, state/displacement norms, pairwise linear CKA, and lagged correlation of node displacement magnitudes at lags0..4. Compare native lags with episode-shuffled traces and reversed local order. Report node-specific temporal response to reactivation, using key probe accuracy at the first four DATA events. Local-history order controls compare ordered [delta_{t-1},delta_t] with reversed, shuffled, integrated sum, first-only, and final-only features, with h_t retained in all conditions. Essential chronology is not claimed unless order-independent and endpoint controls fail to explain the effect. Do not equate a role label, geometry, or decoder result with causal importance.

TOPOLOGY: report all above for each arm. Predefined paired contrasts RING-DISCONNECTED, RANDOM-DISCONNECTED, FULL-DISCONNECTED, LEARNED-FULL, RING_HET-RING, FULL_HET-FULL, and each swarm-MONOLITHIC, separately for competence, joint H1, HS, and complementarity. These are descriptive architecture-conditioned contrasts; no global winner is declared. Capacity differences and the fixed input-port asymmetry must remain explicit.

## Separate causal interventions — after native measurement

COMMUNICATION: freeze weights and evaluate native, zero incoming messages, time/type-stratified cross-episode shuffled messages, and fixed degree-matched rewiring. For FULL, rewiring is topologically identical and recorded as noninformative; for DISCONNECTED it is an identity control. A trained graph's communication-dependence candidate requires native-minus-zero and native-minus-shuffled RETURN_EARLY gains both A+, plus positive DATA difference. Compare with the independently trained DISCONNECTED arm; an out-of-distribution ablation alone cannot establish necessity of communication as an architecture. No intervention is used to redefine native information.

NODE ABLATION: for each node, freeze its outgoing messages to zero during a full episode and separately zero its contribution only at the final readout. Report changes in DATA/return accuracy, cross-entropy, and hidden-key accessibility. Distinguish communication contribution from direct readout contribution. Preserve negative and compensatory effects; no node is assigned a semantic role in advance.

STATE-REPLACEMENT INFLUENCE: select up to1024 deterministic eligible DATA checkpoints with three following DATA events. Replace one node's state by a donor's native state at the same time/current event type/payload from another episode, preferring different active keys without using labels for the actual learned controller. Continue all nodes under identical recipient future inputs for three steps. Report the8x8 normalized response matrix, terminal output total variation, and accuracy damage separately. Compare matched-key and different-key donor controls. These are explicitly off-manifold causal probes; response magnitude is not automatically useful information or native propagation. No tangent/phase geometry is forced.

MATCHED-HISTORY HYSTERESIS: construct paired legal episodes with identical key definitions, semantic event schedule, and identical continuation from the final ACTIVATE event, but independently resampled earlier DATA payloads. Compare the complete64 states at the shared checkpoint, subsequent states, output total variation, and functional correctness under identical future inputs. Geometric differences alone do not establish functional hysteresis; identical complete states under the same map cannot produce distinct deterministic futures. Preserve any evidence of functional equivalence despite geometric separation.
