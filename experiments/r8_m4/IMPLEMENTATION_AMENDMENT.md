# R8-M4 Outcome-Free Implementation Amendment

**Timing:** frozen before smoke execution and before any fresh-seed outcome inspection.

The preregistered F1/F2/F3 wording left a narrow non-exhaustive case: successful suppression with mean `Delta_EB <= -0.02` but an uncertainty interval that still includes zero would satisfy neither F1 nor the originally worded F2/F3 harm criteria.

To make the classifier exhaustive without making a positive result easier:

1. `V` remains baseline-lineage validity failure.
2. `F0` remains manipulation failure.
3. `F3` remains exactly the strict preregistered selective-functional-contribution criterion.
4. `F1` remains exactly the preregistered performance-preservation criterion.
5. **Any valid, successfully suppressed outcome that is neither F1 nor F3 is classified F2 — ambiguous functional effect.**

Thus F2 includes significant nonspecific harm and threshold/uncertainty cases. No F3 threshold is relaxed, and no failed manipulation can be interpreted functionally.
