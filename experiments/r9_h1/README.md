# R9-H1 — Hybrid Interaction Anomaly Screen

This directory implements the preregistered R9-H1 experiment. Scientific thresholds and architecture/interaction arms are defined in `PREREGISTRATION.md` and must not be changed after outcome inspection.

Implementation workflow:

1. outcome-free smoke test;
2. eight fresh family seeds;
3. frozen cross-seed aggregate classification;
4. aggregate record committed to a dedicated results branch, not `main`.

The experiment is intentionally an anomaly screen rather than a performance contest.
