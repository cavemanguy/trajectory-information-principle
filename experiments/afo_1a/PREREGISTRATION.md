# AFO-1A — Frozen recurrent source qualification

Status: preregistered before implementation smoke and scientific outcomes. This is a new experiment, not a rescue of R9-T1/H1/S1. Parent main: `5ebdfa57546a9950e7866bb3abae5770c3e43924`. Preserve all prior results. The broad native-trajectory question remains open.

## Question and scope

Can a conventionally trained recurrent model learn a small hidden-mode register task well enough to serve as a frozen, instrumented organism for later Active Flow Observer experiments? This run qualifies sources and validates replay. It does not train a semantic observer, establish the internal algorithm, test active information gain, or claim real-time interpretability. Source qualification is a prerequisite, not the project's primary scientific objective. No AFO-1B observer experiment is automatically authorized by a failed gate.

## Frozen task

A reference interpreter holds an accumulator `a` in Z8 and a mode `m` in {LOAD, ADD, XOR, ROTL_XOR}. Each episode begins with START(a), followed by three blocks, each containing MODE(m) and eight DATA(x) events. Each block independently samples a mode; all initial values, modes, and payloads are uniform. The 28 legal events are padded to length32. At DATA, the interpreter performs one operation, emits the resulting accumulator, and updates it: LOAD: a'=x; ADD: a'=(a+x) mod8; XOR: a'=a xor x; ROTL_XOR: a'=rotl3(a,1) xor x. Non-DATA events have no supervised output. The current DATA input contains x, not the current mode or accumulator. No reference operation or accumulator label is passed into the neural forward path. Chance output accuracy is12.5%; operation-label chance is25%. The interpreter records before/after registers, operation, inputs, and outputs in a separate privileged trace. These are reference-task semantics, not known facts about the neural implementation.

## Source model and training

One GRU source per fresh seed: type embedding16, payload embedding16, summed and LayerNorm32; GRU32->64, one layer, no dropout; readout Linear64->64, GELU, Linear64->8. All recurrent states start at zero. The same parameters are reused at every event. No auxiliary operation, register, geometry, trajectory, or observer loss. Train only DATA output cross-entropy. PyTorch float32 CPU, Python3.11, deterministic algorithms, single thread. AdamW lr0.001, weight decay0.0001, global gradient clipping1.0. Exactly1600 optimizer steps, batch64, fresh episodes every step, final checkpoint only for evaluation. Record loss/gradient norms at steps divisible by100 and final; no validation-based checkpoint selection, early stopping, curriculum, or outcome-driven training extension. Freeze dependencies and all source code before scientific execution.

Fresh independent family seeds: [4109,4133,4153,4177,4201,4219,4241,4261]. SHA256-derived disjoint namespaces for initialization, train, held-out evaluation, replay, and future observer splits. Evaluation is1024 episodes/family; source train and validation/probe datasets are separate. Use all eight families, never select the best seed. The source checkpoint is the exact final state_dict, with SHA256 of its serialized bytes, source commit, and environment manifest. Preserve all checkpoints even on failure. No source weights are trained on AFO observer labels.

## Hard stops and frozen classification

Before release, an outcome-free smoke must establish reference-interpreter arithmetic and schedule, target exclusion, tensor shapes, finite forward/backward, causal-prefix invariance, deterministic replay, exact source-state restore, zero-action identity, bounded perturbations on independent forks, frozen parameter fingerprints, and classifier self-tests. Failure stops scientific launch; only documented implementation repairs before outcomes are permitted. Missing family, nonfinite result, source/protocol mismatch, missing checkpoint, or failed replay identity gives AFO-1A-X; do not silently aggregate a subset or replace a seed.

A family is source-qualified only if held-out DATA accuracy>=0.65, each of the four operation accuracies>=0.50, and final-block DATA accuracy>=0.60. These are modest competence floors, not task mastery or evidence of semantic recovery. The primary family-wide gate is all eight sources qualified. If any misses, classification is AFO-1A-Q0 and no learned-source observer experiment proceeds under this protocol. If all pass, classification is AFO-1A-Q1; all eight frozen sources are eligible for a separately preregistered observer experiment. Report means, standard deviations, ranges, per-seed values, and paired seed-bootstrap95% intervals with20000 resamples, RNG91095. No post-hoc gate changes, extra steps, new seeds, or checkpoint substitution.

## Replay and native evidence

For each source, use the existing AFO `FrozenSystem` interface with an adapter that captures the complete recurrent hidden state, event index, frozen parameters, and any mutable continuation state. The native path is read-only to the observer. Forks must own independent storage and match the source fingerprint. Preserve native state and output traces from held-out episodes, step indexes, monotonic timestamps with units, and exact checkpoint/source hashes. A zero-action paired continuation must reproduce the native path bitwise on CPU; a nonzero bounded vector intervention must leave the source unchanged. Integer-bit XOR is only legal on declared unsigned integer inputs, never arbitrary floating-point memory bits. No external process, remote service, or physical equipment is probed.

This stage may report descriptive hidden-state norms, displacement norms, and ordinary task labels, but no semantic-information or dynamical-mechanism discovery is classified here. All such diagnostics are labeled exploratory and cannot rescue source competence. The later AFO-1B protocol must freeze observer architectures, information-matched input/output and complete-state baselines, passive history/order controls, disjoint perturbation banks, controller-only leakage audits, structured semantic labels, uncertainty/abstention, and statistical gates before training. Native observation precedes isolated causal probes. Reference-task labels cannot establish a neural model's actual internal algorithm; that requires separately testable causal hypotheses. No current run promises millisecond logic recovery.
